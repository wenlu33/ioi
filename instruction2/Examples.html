Clue Balls and Box A Color

When you choose Box A, the color of the Ball in Box A is the same for everyone in your group. However, each participant receives their own Clue Ball, drawn separately from a hidden Clue Box based on the Ball in Box A. You will only see your own Clue Ball — you will not be told the Ball in Box A color or which Clue Box was used.


Example 1
  • The computer would use Clue Box X, which contains only "yellow" balls.
  • Everyone in the group would receive a Clue Ball: "yellow".
What You See What One Group Member Might See
"yellow" "yellow"

When the Ball in Box A is YELLOW, all participants receive a Clue Ball of "yellow".


Example 2
  • The computer would use Clue Box Y, which contains 2 "blue" balls and 1 "yellow" ball.
  • Each group member will independently receive a Clue Ball. You may receive "yellow" or "blue", and the same applies to other group members.

(The Clue Ball color can be different for each person)
